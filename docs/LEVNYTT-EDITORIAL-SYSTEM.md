# LevNytt Editorial System v1

The Editorial System standardizes reading experience while preserving the job of each page.

## Shared reading rules

- State one user-facing promise in the title and H1; retain a single H1.
- Start with a concise introduction that explains scope, limits, and why the reader should continue.
- Use an H2-led hierarchy; each section answers one question and paragraphs remain scannable.
- Present factual claims with linked or named sources; separate evidence from interpretation.
- Use semantic callouts only for method, warning, definition, or action context. Do not use callouts as decoration.
- Use quotations only with attributable source context.
- Show author, update information, and any applicable disclosure near the reader-facing content.
- Use CTAs only where they extend the page's purpose. A consumer-information page may intentionally use no commercial CTA.
- Use an internal-link cluster for relevant next reading, not arbitrary cross-promotion.
- Use FAQ only when genuine recurring questions are answered by the page.

## Page-purpose contracts

| Content type | Primary reading contract | CTA / disclosure rule |
| --- | --- | --- |
| Consumer information | Explain a defined question without overclaiming | No commercial CTA required; disclose neutrality where relevant |
| Authority / reference | Provide traceable definitions, method, and sources | Prefer internal learning paths |
| Health and wellness | Explain evidence limits and avoid diagnosis/treatment claims | Product/referral CTA requires visible disclosure |
| Product | Explain product scope, price/claim boundaries, and alternatives | Product disclosure required |
| NeoLife product or opportunity | Separate consumer facts from opportunity claims | Sponsored/referral relationship must be explicit |
| Referral / affiliate destination | Explain the reason for the link and relationship | Disclose before the action link |
| Personal authority | Identify the author and role without presenting opinion as evidence | No implied independent verification |

## Swedish voice

Write calm, direct Swedish. Prefer definitions, conditions, and sourceable facts over hype, urgency, or income/health promises. Distinguish what is known, what is limited, and what the reader can verify next.

## Editorial primitives

The Informational Article v1 shell provides eyebrow, byline, punchline, takeaways, callout, method note, responsive table, internal-link cluster, FAQ, author block, disclosure, and CTA primitives. Use only the primitives that support the page contract.
